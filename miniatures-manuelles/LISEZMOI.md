# Miniatures faites à la main

Une image ici remplace la miniature automatique de l'épisode du même nom.

- Nom du fichier : `<id-de-l-épisode>.png` (l'id est le nom du dossier dans `episodes-b/`, par exemple `costco-carte-membre.png`).
- Format : PNG, exactement **1280×720**, **2 Mo maximum**.
- Elle est copiée telle quelle vers `episodes-b/<id>/miniature.png`, sans retouche ni contrôle de lisibilité.
- Si le fichier est mal dimensionné ou trop lourd, l'épisode passe en `quarantaine` avec la raison (rien n'est publié avec une mauvaise miniature) ; corrige l'image et relance.
- Dépose-la **avant** que l'épisode arrive à l'état `controle` (c'est à ce moment que la brique miniatures travaille).
